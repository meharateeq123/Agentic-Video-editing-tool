# Visual Relevance Rule (HARD — applies to every video)

These are non-negotiable. A scene that violates any of them is not finished, even if it
renders cleanly and the footage is real.

## 1. Read the VO and the script before choosing anything
The voice-over is the timeline source of truth — every cut, slot length and transition is
derived from VO timing. The script supplies context and intent. Analyze both BEFORE
selecting a single visual.

## 2. The visual must match what the VO is SAYING
Not what it mentions. A name match, a keyword match or a track match is not relevance.
Ask what the viewer is being told at that exact second, and show that.

The failure mode this exists to prevent: narration says "he has not won a race in 49
starts" while the screen shows him lifting the championship trophy. Both clips are real
NASCAR footage of the right driver. It is still wrong, because it contradicts the
sentence being spoken.

## 3. First five minutes: zero compromise
No weak matches, no "close enough", no generic filler. Search multiple queries and
multiple sources until the right footage is found.

## 4. Never repeat a clip inside a scene
Do not reuse the same clip, and do not use two offsets of the same source video, to fill
duration. One scene = one visual journey made of DIFFERENT relevant shots.

## 5. No static ending
Never freeze the last frame and never hold a still image for the final 2-3 seconds. The
whole assigned duration must carry real motion. Every slot must be capped to
(clip duration - margin) so a slot can never outrun its clip.

## 6. No burned-in text in source visuals
Never use an image, thumbnail, screenshot or clip that already carries text, captions,
headlines, watermarks, lower thirds or overlaid typography when it can be avoided. We add
every text layer ourselves. The visual asset and the text layer stay separate.

## 7. Motion graphics: use them, then move on
Use a motion graphic when it adds value. Never leave one on screen long enough to become
repetitive — change the visual before that point.

## 8. Locations get the globe treatment
When introducing a stadium or location, prefer globe/map -> location -> stadium animation
over a plain establishing shot.

## 9. When nothing relevant exists, build it — never substitute junk
If genuinely relevant footage cannot be found after real searching, DO NOT drop in
irrelevant footage. Use our own motion graphic, animated image, map, statistic card or
other relevant custom visual instead.

## 10. Visual variety across long VO sections
Longer narration gets multiple visual TYPES — clips, B-roll, images, graphics, maps,
statistics, animations. Keep the edit dynamic.

## 11. Transitions
No unnecessary gap longer than 1 second. Keep such transitions around 0.7s unless the
narration itself calls for a longer beat.

## 12. Priority order
relevant clip > relevant B-roll > relevant animated image > custom motion graphic >
NEVER irrelevant footage.

## 13. Final check before every placement
Ask: "Does this visual make sense with what the viewer is HEARING right now?"
If the answer is no, reject it and search again. Do not place it and move on.

## Goal
The finished video must read as a professionally edited sports/news documentary, with
every visual intentionally matched to the narration.
