Superseded update: this memory originally said named-person photos should be **full-frame** (not a small card). That was tried on berry1's Scene01/Scene06 (a NameReveal component that swapped the real footage out entirely for a full-bleed photo). The user immediately reverted it: "PICTURE KO CARD MAI HI LAGAO JAISAI HUM PHLAI LAGA RAI THA CLIP K UPAR" (put the picture back in a card, like we were doing before, on top of the clip). berry1 was rebuilt using the original IdCard pattern (photo + name + role in a card, overlaid on real footage, same as [[reddick-southern-500-film]]'s bell1 pattern) and that's the current standard — cleetus4 was built the same way.

**Current rule:** Named-person beats use the small ID card (photo left, name/role text right, ~190x190 photo, over a blurred/dimmed real-footage bed) — this is the established, confirmed-preferred look. Do not reintroduce a full-frame photo swap-out without the user asking for it again specifically.

**General direction that still stands:** the user does still want shorts to feel more produced than plain clip-cutting — number/stat cards (bell2's StandingsCard, berry1's NumberCard, cleetus4's NumberCard), modern transitions, and CapCut captions are the agreed toolkit. The full-frame photo idea specifically was the part that got reverted — don't conflate "more modern" with "full-frame photo."

**Why the first rule existed:** User's exact words at the time: "yai to srf clipping thi ab tak" (this has just been clip-cutting so far). That feedback was real and the number/stat-card work since then has addressed it — but the specific full-frame-photo interpretation was wrong and got corrected.
