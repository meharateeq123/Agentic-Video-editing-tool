On 2026-09-29 the user set a floor: every script from now on must be at least 1300 words ("1300 words se kam nahi likhni script ab se"). This replaces the earlier rule of "about 60–70 words more than the last script" (see [[euler-film]]).

Context: the Laplace script ("The Equation That Makes Calculus Disappear", `manimgl\laplace\script.txt`) came out at 1396 words and the user said "very good". Keep it as is and don't trim it. At their VO pace (~180 words/min, e.g. Euler: 1156 words = 6:24) it comes to about 7:45.

**Why:** longer, heavier scripts; see [[manimgl-scripts-must-be-heavy]].

**How to apply:**
- Before handing over a script, count the real words with a split on whitespace, not an estimate. I once reported 1280 when it was really 1396.
- Stay at 1300 or more.
- Write equations as spoken words, because the VO is TTS. This inflates the count, which is fine.
- Deliver VO scripts as plain narration in a code block, with no visual notes, so the user can paste straight into TTS.
