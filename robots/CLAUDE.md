# Robot sports films

These are the rules for robot videos: humanoid robot sports, robot fighting and robot racing. The user set them across robots1, robots2 and robots3 (October 2026). They are standing rules, not per-film preferences.

Each film is built in `D:\flick\output\robotsN\` with this layout:

```
output\robotsN\
  script.txt      the pasted script, verbatim
  plan.json       beats: word anchor + source + start time (+ crop) -- generated by qc\mkplan.mjs on robots3
  build.mjs       words -> beats -> remotion\src\data.ts, bakes every bed to remotion\public\bed\bNN.mp4
  grid.mjs        QC sheets (6 frames per bed) -> qc\beds_NN.jpg
  sheet.mjs       contact sheet of a source; sheet2.mjs = 1-4 fps detail sheet of a window
  dl\             raw yt-dlp downloads (never in remotion\public)
  remotion\       copied from the last robots film; node_modules is a junction
```

Studio runs on its own port (robots1 3013, robots2 3015, robots3 3016). Start it in its own minimized `cmd /k` window so it doesn't die with the shell. Render only when the user asks.

---

## 1. Relevance is 100%

"jo chz boli jari ho wohi dikhai jai": what is on screen must be exactly what the line says.

- A line about a specific race, record or time shows that race, record or time. For example, an 8.64 line shows the 8.64 final, never the 9.39 heat, even from the same robot and the same Games.
- A line about an action shows that action. "race, jump, compete" needs racing, not boxing.
- A line about hardware, motors or balance shows a robot body, legs, or a balance or fall test, not a crowd.
- A line naming a person shows that person, e.g. Usain Bolt for "Bolt's 9.58".
- A near-miss is not acceptable. If the right footage isn't in the downloads, search YouTube again (official channels first: World Humanoid Robot Games, Unitree, EngineAI, Boston Dynamics, BattleBots, NHRL, RoboCup, plus AP, Reuters, CGTN and CNA news), or raise it before building.
- Real footage only. Reject anything that looks AI-generated, and anything from movies (Real Steel, Pacific Rim).

## 2. The whole subject stays in frame

"koi robot ka face na katai, har chz camera mai buht achi tarah ai"

- A robot's or person's head and face must never be cut by a crop. Leave headroom above the head.
- Broadcast close-ups often put the head right under a corner logo. Don't zoom past the logo and lose the head. Instead, cover the logo with a clean neighbouring patch (the `delogo` field in build.mjs, `x:y:w:h:sx:sy`) and lay your own event panel over that corner.
- If the subject is already out of frame in the source (e.g. the weightlifting robot), replace the clip.

## 3. Clips are 3-4 seconds, with plain cuts

- Every clip is between 3.0 and 4.0 s. build.mjs prints `BEAT LENGTH` for any beat outside that range. Shorten the tail if the last beat runs long.
- Use plain hard cuts between clips: no punch, whip, glitch or flash transitions.
- A clip must not contain a hidden camera cut. Scene detection at 0.28 misses many, so check 6 frames per bed on the grid. For exact cut points run `select='gt(scene,0.15)',showinfo`.
- No clip or source window is used twice, the hook included (build.mjs prints `OVERLAP`).
- A clean shot that is slightly short may be slowed down (`slow: 1.1`), but only if the subject is static, like a scoreboard.

## 4. Clean picture

- No burned-in subtitles, captions, news lower-thirds, channel bugs, race timers or watermarks. Crop or patch them out, and if neither works, use a different moment.
- Use h264/avc1 downloads only, never AV1: `bv*[height<=1080][vcodec^=avc1]+ba[ext=m4a]/b[vcodec^=avc1]`.

## 5. Hook (first ~10 s)

Use the approved Hook10 style (template: `.claude/skills/flick/saved-animations/modern-hook-10s/`; robots3 version: `output/robots3/remotion/src/components/Hook.tsx`).

- The sharp clip sits in a rounded box, with the same clip blurred behind it.
- Cut hard on each VO phrase.
- One small kinetic graphic per beat, such as 100M, a rolling 8.64 clock, a ROBOT vs BOLT split, or IMPOSSIBLE?.
- Words go in the blurred strip under the box, so text never covers the action.
- Music only, no SFX. Alternate the two mixkit tracks from video to video.
- Every hook clip obeys rules 1-4 as well.

## 6. Motion graphics

- Each graphic sits on the clip that shows its subject, timed to the real impact frame (punch, knockdown, finish line). Find that frame on a 4 fps sheet, and have the graphic leave 12 frames before its clip cuts.
- While a big graphic (team cards, bracket, FaceCard, end title) is up, blur the bed behind it (~7 px) and dim it ~22%. Small strike tags leave the action sharp.
- Keep text small, and never over a face.
- No subtitles unless the user asks.

## 7. Facts

Check every number and name before it goes on screen. If a script claim can't be verified (e.g. robots3's "Tian Jiao Dui" team), it stays in the VO but never goes into a graphic.

Verified on robots3: the 8.64 s run was on Aug 26 2026 at the 2nd World Humanoid Robot Games in Beijing, by Tiangong Ultra (X-Humanoid). The 8.86 s semi and 9.39 s heat came earlier. Bolt's world record is 9.58 (Berlin 2009).

## 8. Before showing the user

1. Run grid.mjs and look at every bed's first, middle and last frames, checking relevance, full subject and a clean picture.
2. Render stills of the hook and of every graphic with `npx remotion still`.
3. Make sure Studio is actually serving: `curl http://127.0.0.1:<port>/` must return 200.

Per-film notes are in `claude-memory/robots1-film.md`, `robots2-ultimate-bots.md` and `robots3-film.md`.
